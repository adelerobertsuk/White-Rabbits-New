# White Rabbits

Daily habits, a private journal, and a first-morning ritual. Say the words. Collect a little luck.

Mobile-first, editorial, and entirely on-device. No accounts, no backend, no third-party scripts.

## See it locally

The preview server is `http://127.0.0.1:4173/` when running. From this folder:

```bash
python3 -m http.server 4173
```

Then open that URL on this Mac, or on your phone on the same Wi-Fi.

## Preview

- `?first=1` treats today as the first of the month, so you can rehearse the alarm and magic words.
